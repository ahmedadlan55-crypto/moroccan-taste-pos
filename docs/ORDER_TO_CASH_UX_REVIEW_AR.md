# مراجعة UX — قسم «المبيعات والعملاء»

## نظام التصميم
- **مسافات 8pt**، بطاقات نظيفة، زوايا `2xl`، ظلال ناعمة، هوية Teal/Saffron متسقة مع قسم المستودعات.
- **RTL عربي كامل**؛ كل الأرقام **إنجليزية 0-9** داخل `dir="ltr" tabular-nums` لمحاذاة نظيفة وسط النص العربي.
- Tables احترافية برأس لاصق و`overflow-x` للجوال. أزرار إجراءات لاصقة في صفحات التفاصيل (رأس الصفحة).
- Micro-interactions خفيفة (Framer Motion على انتقال المسار). `focus-visible` على كل عنصر تفاعلي.

## إمكانية الوصول (WCAG AA)
- أهداف لمس ≥44px (أزرار `min-h-11`، عناصر التنقّل `min-h-14`).
- Drawer: `role=dialog`/`aria-modal`، حبس التركيز، Escape يغلق، استعادة التركيب.
- SearchableEntityCombobox: `role=combobox/listbox/option` + `aria-activedescendant` + تنقّل لوحة المفاتيح (↑↓ Home End Enter Esc) + Portal فوق الحوارات.
- روابط «تخطٍّ إلى المحتوى»، تباين ألوان كافٍ، حالات focus واضحة.

## الأنماط الموحّدة
- **الحالات**: Loading skeleton، Empty (برسالة + إجراء)، Error + Retry، PermissionDenied، Dormant.
- **StatusPill**: لون + تسمية عربية لكل حالة مستند (مسودة/صادرة/مدفوعة جزئيًا/مدفوعة/مُرحّل/معكوس…).
- **Money/Num/DateCell**: مكوّنات موحّدة تضمن الأرقام الإنجليزية والتنسيق (SAR + Gregorian).
- **Pagination** خادمية موحّدة، **Toolbar** بحث + فلاتر متسقة عبر كل القوائم.

## القرارات وقابلية الاستخدام
- **قسم واحد** فقط في القائمة الرئيسية؛ تنقّل ثانوي داخل القسم (Sidebar + MobileNav) مُصفّى حسب الصلاحية.
- **الفاتورة الصادرة immutable** في الواجهة: لا زر تعديل؛ التصحيح عبر «مرتجع/إشعار دائن».
- **منع over-allocation** بصريًا في نموذج التحصيل (تحذير فوري) مع الاعتماد النهائي على الخادم.
- **بوابة الائتمان**: أمر البيع الآجل يتطلب عميلًا (checkbox «بيع آجل» + منتقي عميل)، والرفض يأتي من الخادم برسالة عربية واضحة.
- **الطباعة**: كشف الحساب والفاتورة بتخطيط A4 (`no-print` يخفي التنقّل والإجراءات).

## نقاط تحسين مستقبلية (موثّقة، غير حاجبة)
- تقليل حجم الحزمة الرئيسية (558kB) عبر `manualChunks` (التقارير مُجزّأة بالفعل).
- إضافة to" toast" مركزي بدل التنبيهات المضمّنة في بعض النماذج.
- تكامل واجهة POS (منتقي عميل في الكاشير) — مُدرج كعمل لاحق.
