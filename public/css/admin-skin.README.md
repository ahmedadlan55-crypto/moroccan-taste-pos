# admin-skin.css — ADLAN Design-System skin

طبقة CSS واحدة تطبّق **نظام تصميم ADLAN** على الواجهة القديمة بالكامل **بدون تغيير سطر واحد** من كود HTML/JS/الـ Routes.

## التثبيت

في `public/index.html` — يُحمَّل **آخرًا** (بعد `style.css` وباقي ملفات CSS) لأنه يعتمد على `!important` لتجاوز الأنماط الأصلية بأمان:

```html
<link rel="stylesheet" href="/css/style.css">
<!-- … باقي ملفات CSS … -->
<link rel="stylesheet" href="/css/admin-skin.css">   <!-- آخر سطر -->
```

## ماذا يفعل (مطابقة ADLAN Design System)

- **الهوية:** كحلي `#0E1726` (chrome) · بترولي واحد `#0E7490`/`#155E75` (accent) · بترولي‑ناعم `#E6F3F7` · خط IBM Plex Sans Arabic. لا ألوان بنفسجية.
- **الأزرار:** ارتفاع 40px · زوايا 10px · 5 حالات (رئيسي/ثانوي/خفيف/خطر/معطّل).
- **الحقول:** 40px · زوايا 8px · حدود `#CBD5E1` · تركيز بترولي 3px.
- **البطاقات:** زوايا 14px · حدود `#E3E8EF` · ظل خفيف (مستوى sm).
- **الجداول:** رأس `#F8FAFC` · صفوف كثيفة · أرقام مونو LTR.
- **الحالات (Badges):** بيضاوية بنقطة · 14 حالة بألوانها الدقيقة.
- **الظلال:** 3 مستويات فقط (بطاقات/قوائم/نوافذ).
- **القائمة الجانبية:** كحلية + عنصر نشط بحبّة بترولية + بلاطة شعار.

## ماذا لا يلمس

- ❌ لا يحذف أيّ قسم · ❌ لا يغيّر أيّ route أو منطق · ❌ لا يلمس قاعدة البيانات · ❌ لا يكسر submenu أو navigation.

## المرجع

الرموز الكاملة في `public/shared/design-tokens.css`. نمط القشرة يطابق تطبيقات React في `frontend/*/src/components/app-shell/`. مصدر النظام: ملفات Claude Design (`ADLAN ERP` + `Design System`).
