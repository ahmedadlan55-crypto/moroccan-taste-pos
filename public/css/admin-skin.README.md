# admin-skin.css — Drop-in Visual Upgrade

طبقة CSS واحدة تُحدّث الهوية البصرية لمنتجك بالكامل **بدون تغيير سطر واحد** من كود HTML/JS/الـ Routes.

## التثبيت

في `public/index.html` (و `views/app-content.html` و `/pos/index.html` إن أردت):

```html
<!-- ابقِ هذه السطور كما هي -->
<link rel="stylesheet" href="/css/style.css">
<link rel="stylesheet" href="/css/warehouse-ops.css">

<!-- أضف هذا السطر في النهاية -->
<link rel="stylesheet" href="/css/admin-skin.css">
```

**ترتيب التحميل مهم:** يجب أن يكون `admin-skin.css` آخر ملف لأنه يعتمد على `!important` لتجاوز الأنماط الأصلية بأمان.

## ماذا يفعل

- يغيّر **اللون البنفسجي #7c3aed** ليصبح هوية النظام (بدلاً من الأزرق #0d47a1)
- يلطّف الحواف والظلال والانتقالات
- يحسّن الـ sidebar مع شريط جانبي بنفسجي للعنصر النشط
- يرفع جودة البطاقات والإحصاءات (KPI cards)
- يحدّث الـ POS باللون البنفسجي
- يضيف focus rings موحّدة
- يلطّف scrollbars

## ماذا لا يلمس

- ❌ لا يحذف أيّ قسم
- ❌ لا يغيّر أيّ route أو منطق برمجي
- ❌ لا يلمس قاعدة البيانات
- ❌ لا يكسر submenu أو navigation

## الإزالة

احذف السطر الذي أضفتَه. كل شيء يعود لحالته الأصلية فوراً.

## الاختبار قبل النشر

1. انسخ `admin-skin.css` إلى `public/css/`
2. أضف سطر `<link>` في صفحة واحدة (مثلاً `/pos/`)
3. افتح الصفحة وتنقّل في كل الأقسام للتأكّد
4. إذا أعجبك، طبّقه على باقي الصفحات

## الأقسام المُحسَّنة

| المنطقة | التحسين |
|---|---|
| Sidebar الإدارة | إشارة بنفسجية للعنصر النشط + رؤوس مجموعات أنظف |
| الأزرار | حواف 12px + ظلال ملوّنة + رفع طفيف عند الـ hover |
| البطاقات | حواف 16px + ظلّ أنعم + لمس بنفسجي عند الـ hover |
| الجداول | رؤوس بحرف صغير + تباعد أوسع + ألوان أهدأ |
| الـ Modals | حواف 20px + ظلال أعمق + glass محسّن |
| POS | فئات بنفسجية + بلاطات لطيفة |
| ERP KPI | تدرّجات بنفسجية بدل الزرقاء |
| Toasts | بنفسجي/أخضر/أحمر + خطوط أوضح |

## ملاحظة

هذه طبقة بصرية فقط. إذا أردتَ إعادة تنظيم بنية شاشة معيّنة (مثل dashboard، orders، inventory) بشكل احترافي مع كثافة معلوماتية أفضل، انظر مجلّد `prototypes/admin-v3/` — هو نموذج كامل لما يمكن أن تبدو عليه الإدارة بعد الترقية الكبيرة.
