## UX والوصولية (مقاسة فعليًا في نفس التشغيل)

- **المقاسات:** 1440 / 768 / 375 بكسل — **لا تمرير أفقي** على 375 و768 (فحص `scrollWidth`).
- **RTL** كامل + أرقام/تواريخ عربية؛ MobileNav سفلي لا يحجب المحتوى (padding آمن + لقطات جوال).
- **لوحة المفاتيح:** أول Tab يصل إلى رابط **«تخطٍّ إلى المحتوى»** (WCAG 2.4.1) — مؤكَّد برمجيًا.
- الحالة مرئية لا بالألوان فقط (StatusBadge نقطة+نص)؛ Drawer بمصيدة تركيز + Esc + استعادة التركيز؛ خطوات المعالج تُعلَن بـaria-live؛ `prefers-reduced-motion` مُحترم.
- **الطباعة:** `@page A4` بهوامش 12mm + منع كسر الصفوف/البطاقات عبر الصفحات.
- **الكونسول: صفر أخطاء** عبر كل الصفحات (dashboard/items/lots/trace/expiry/transfers/stocktakes/adjustments/analytics/reports/replenishment).
